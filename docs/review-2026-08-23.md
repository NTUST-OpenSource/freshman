## 高

### 1. 快取寫入失敗會丟掉已經拿到的名單

`src/lib/contributors.mjs`

```js
pending ??= fromApi()
  .then((list) => { fs.mkdirSync(...); fs.writeFileSync(CACHE, ...); return list; })
  .catch((err) => { /* 當成 API 失敗處理 */ });
```

`.catch` 掛在 `.then` 之後，所以 `mkdirSync` / `writeFileSync` 拋錯（唯讀檔案系統、權限、磁碟滿）會被當成 API 失敗：log 印「GitHub API unavailable」（與事實不符），已經成功抓到的 `list` 被丟棄，改吃舊快取或回 `null`。

寫入應該獨立 try/catch，失敗只記一行 log，仍回傳 `list`。

### 2. 退化路徑本身可能讓 build 失敗

同檔案。`catch` 內的 `JSON.parse(fs.readFileSync(CACHE, 'utf8'))` 沒有保護。上一次寫入若被中斷（build 被 kill、磁碟滿），快取是截斷的 JSON，`JSON.parse` 拋錯 → promise reject → `await getContributors()` 在頁面 frontmatter 拋出 → **build 中斷**。

這條路徑存在的目的就是「API 失敗也不要擋住部署」，目前它自己會擋。讀取與 parse 也要包 try/catch，失敗回 `null`。

## 低

### 6. 不可點的卡片仍有 hover 上浮

`src/components/PersonCard.astro`。`.person:hover` 的 `translate: 0 -2px` 套用在所有卡片，但沒有 `github` 的人（目前是 Keng Liao）沒有 stretched link，整張卡不可點。滑鼠移上去會有可點的暗示，實際上只有右側飛機能按。

### 7. `Founder` 角標可能被長姓名壓到

`.person__tag` 絕對定位在卡片右上角，`.person__id` 沒有預留右側內距。目前六個人的姓名都短，不會發生；資料是固定的歷史事實，所以只是記錄。

### 8. 系別提示的兩條關閉路徑沒有共用收尾

`initDeptHint`。按 ✕ 關閉後，掛在系別按鈕上的 `{ once: true }` 監聽器仍然武裝著，之後第一次點系別鍵會再跑一次 `dismiss()`。結果無害（重複寫同一個 localStorage 值、移除不存在的 class），但兩條路徑應該共用一次性的收尾。

### 9. 空陣列與失敗沒有分開處理

`src/pages/thanks.astro` 以 `contributors === null` 判斷失敗，但 API 回空陣列時會渲染一個空的 `<ul class="gh">`。本 repo 不會發生。

### 10. 系別提示不吃 Escape

系別選單可以用 Escape 關閉，提示卡不行，只能點 ✕ 或點開選單。
