一些不屬於任何一篇、但每年都會被問的問題。

## 新生入學指導一定要參加嗎

不一定，但**下午的各系新生茶會建議去**。

- 上午的入學指導是全校性的行政說明，通常會發環保筷之類的小禮物
- 下午的系新生茶會才是重點：認識同班同學與學長姐，很多新生群、直屬制度都是從這裡開始的

各系茶會的時間不一定相同，多半排在新生入學指導當天下午。詳細時間看各系系學會的粉專，或直接在新生群裡問，聯絡方式見 [[student-organization|系學會社群]]。

## 兵役調查表怎麼填

新生入學時要填兵役調查表，最容易搞錯的是「申辦學生兵役種類」這一欄。

::card[兵役調查表填表說明]{href="https://student.ntust.edu.tw/p/406-1053-79901,r1678.php?Lang=zh-tw" desc="學務處生活輔導組的官方逐步說明"}

![兵役調查表「申辦學生兵役種類」欄位的填寫說明](/images/other-question/military-service.webp "學務處生輔組公告的填表說明：申辦學生兵役種類各選項適用對象")

各選項的適用對象：

| 選項 | 適用對象 |
|---|---|
| 緩徵（限未當兵） | 需要辦理緩徵、且不屬於下方「系統顯示年次」的學生 |
| 儘後召集 | ==已服完兵役者==，並須一併編輯兵籍資料 |
| 民國 ○○ 年次（含）以後出生 | 系統顯示之年次出生者**務必選此項**，不可選「緩徵」 |
| 替代役（已服完） | 已服完替代役者；未服完請選「緩徵」 |
| 逾齡 | 已超過 33 歲 |
| 僑生或外籍生 | 依身分別選填 |
| 其他（除役、免役） | 其餘情形 |

:::warning
表格內容依學務處當年度公告為準，上面的整理僅供對照。填錯要重跑一次流程，填之前先確認自己的年次落在哪一類。
:::

## 學籍系統的資料都一定要填嗎

**能填就填。**

- 現在少填的欄位，教務處之後還是會叫你補
- 可以一次做完的事，不要做兩次
- 有些欄位會影響後續的獎助學金、就學貸款與各項申請資格

## 其他常被問的

:::qa[系服建議買嗎？]{by="臺科學長姐" date="2022-08-18"}
有些系繳系費就會送、有些系另外收費。系服跟高中的班服一樣是一種團體象徵，常常在系上團體活動（例如運動會進場）時穿。要不要買看個人意願，不買也不會怎麼樣。
:::

:::qa[會有直屬學長姐嗎？]{by="臺科學長姐" date="2023-08-17"}
各系制度不同，直接問系學會最準。
:::

:::qa[教科書要買實體還是電子書？]{by="臺科學長姐" date="2022-08-30"}
沒有標準答案。iPad 的價值在於不用每天揹重書，但實體書在做練習時比較順手。

如果決定用平板，記得不要「買前生產力、買後 Netflix」。另外也不是每本書都找得到電子檔，找得到的來源也不一定合法。更完整的比較見 [[life|校園生活]]。
:::

:::qa[通常會去選修臺大的課嗎？]{by="臺科學長姐" date="2024-08-01"}
可以依自身排課狀況決定。大一大二很多時候都被必修佔滿，不過還是蠻建議去修看看三校的課。選課階段與規則見 [[course-select|選課]]。
:::

:::qa[沒有 Facebook 帳號，可以用家人的帳號加入頭殼板嗎？]{by="臺科學長姐" date="2025-08-11"}
建議用自己的帳號。管理員審核時會看個人檔案有沒有填學校資訊。
:::
