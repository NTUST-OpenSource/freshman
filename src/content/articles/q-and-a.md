## 選課與課程

:::qa[8/15～8/18 的那次選課不是要比網速吧？是登記自己的志願序嗎？]{by="臺科學長姐" date="2025-08-13"}
理解正確，選課分成兩個階段：

1. **第一階段**排志願序，由電腦抽選
2. **第二階段**搶課，有名額限制的課在這個階段選滿為止

完整流程見 [[course-select|選課]]。
:::

:::qa[國文排了「表達與文學閱讀」和「新生中文說寫專題」兩門，如果都中籤，是不是上學期就修完了？]{by="臺科學長姐" date="2025-08-20"}
照理說兩門必修是衝堂的，不可能同時選到。志願序抽選時，同時段的其他志願會自動作廢。
:::

:::qa[英文課程是選課時就要選嗎？還是等分級考完會自動排進去？]{by="臺科學長姐" date="2022-08-18"}
如果你被分到的模組有「大一共同必修英文」，學校會幫你排進去；如果只有「多元必修英文」，那就要自己選課。

分組必修的規定請參考[語言中心的修課說明](https://lc.ntust.edu.tw/p/412-1070-10776.php?Lang=zh-tw)。制度時有調整，實際設定要等系統開了才知道。
:::

:::qa[英文分班考有考到 B1 以上，在學期間還需要考多益才算達到畢業門檻嗎？]{by="臺科學長姐" date="2022-09-05"}
依照當屆的[英文修課辦法](https://cle-r.ntust.edu.tw/var/file/70/1070/img/502304656.pdf)第六條：

![英文修課辦法第六條條文](/images/q-and-a/english-rule.webp "英文修課辦法第六條：校定英文能力檢測的通過方式")

英檢成績達 CEFR B1（含）級者，得持英檢成績證明向語言中心申請登錄「校定英文能力檢測」，經審核後通過。

不確定的話直接打電話問語言中心，以他們的回覆為準。

不過學長還是建議，**畢業前再去考一次多益比較好**——應徵工作、推甄研究所都會用到。
:::

:::qa[第一週的體育課就會直接上課嗎？球拍要自備嗎？]{by="臺科學長姐" date="2022-08-29"}
體育第一週通常會說明上課須知與規定，會不會直接上課看教授。

體育器材都可以借（登記學生證即可），有些老師會統一請一個人借，有些則要求每個人自己去借。習慣用自己球拍的話，建議直接帶上來。
:::

:::qa[「化學實習」在不分系課表是必修，但名額上限 48 人，沒搶到怎麼辦？]{by="臺科學長姐" date="2025-07-28"}
開學直接去教室找老師加簽。通常遇到不分系要修，老師不會拒絕，或是老師會告訴你怎麼解決。

另外，去問你們不分系選化工的學長姐可以最快得到答案。加簽的實際做法見 [[course-select|選課]]。
:::

:::qa[通常會去選修臺大的課嗎？還是臺科的課就修不完了？]{by="臺科學長姐" date="2024-08-01"}
可以考量自身排課狀況再決定。大一大二很多時候都被必修佔滿，不過還是蠻建議可以去修看看三校的課。

臺大與師大的課程要等**全校加退選**階段才開放新生選。
:::

## 系上與社團

:::qa[系服建議買嗎？還是不要浪費錢？]{by="臺科學長姐" date="2022-08-18"}
有些系的系服繳系費就有送，有些系會另外收費。

系服跟高中的科服、班服一樣，是一種團體象徵，通常用於系上的團體活動（例如運動會進場）。要不要買看個人意願。
:::

:::qa[迎新茶會是什麼時候？]{by="臺科學長姐" date="2022-08-24"}
各系新生茶會時間都不相同，通常辦在新生入學指導當天下午的各系時間。

詳細資訊可以查各系系學會的粉專，或在新生群中詢問學長姐，聯絡方式見 [[student-organization|系學會社群]]。
:::

:::qa[資管系會有直屬嗎？]{by="臺科學長姐" date="2023-08-17"}
這個建議直接問系學會。各系制度不同。
:::

:::qa[系學會會費一定要繳嗎？]{by="臺科學長姐" date="2025-08-24"}
不一定，依照個人意願繳交即可。判斷方式見 [[pay|繳費]]。
:::

:::qa[佛學社、區塊鏈研究社、中友會主要的社團活動是什麼？]{by="臺科學長姐" date="2025-08-11"}
可以去各社團的 Facebook、Instagram 看看，也可以在社團博覽會時到攤位問問，這樣可以最快了解各社團的活動與內容。
:::

:::qa[會有很多人跑去參加臺大的社團嗎？]{by="臺科學長姐" date="2024-08-01"}
三校之間的社團都有各自的活動族群，也很多人會跨校參與其他社團的活動。各自有各自的特色，也很常一起辦活動。
:::

:::qa[沒有 Facebook 帳號的同學可以用家人的帳號加入頭殼板嗎？]{by="臺科學長姐" date="2025-08-11"}
建議用自己的帳號加入。沒記錯的話，管理員審核會看個人檔案是否有加入學校資訊。
:::

## 住宿與生活

:::qa[星期五晚上才繳住宿費用，假日銀行不銷帳拿不到繳費證明單，辦理住宿時可以出示手機付款畫面嗎？]{by="臺科學長姐" date="2025-08-24"}
可以，手機下載出示即可。入住需要的其他文件見 [[dorm|住宿]]。
:::

:::qa[教科書推薦買實體書還是用 iPad 看電子書？]{by="臺科學長姐" date="2022-08-30"}
這個問題沒有標準答案。iPad 只是輔助你，讓你不用每天揹那麼重的書；實體書也有實體書的好處，做練習時比較方便。

買 iPad 等於先預支四年的書籍費（加一些生活費）。不過如果決定用 iPad，千萬記得不要「**買前生產力，買後 Netflix**」。

另外，也不是每本書都找得到電子檔，而且大多數網路上能免費下載的電子檔來源都不太合法。更完整的比較見 [[life|校園生活]]。
:::
