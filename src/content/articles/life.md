## 領錢

校內三家超商裡都有提款機，另外幾棟宿舍與郵局也有。開戶前先看看校內有哪幾家銀行的提款機，**同行提款免手續費**，四年下來省的錢比你想的多。

| 位置 | 提款機 |
|---|---|
| 7-11（學生活動中心 1F） | 中國信託 |
| 全家（第三學生餐廳 B1） | 國泰世華 |
| 萊爾富（第一學生宿舍 1F） | 國泰世華 |
| 第一學生宿舍 1F（戶外） | 華南銀行 |
| 第二學生宿舍 1F（室內） | 華南銀行 |
| 校內郵局 | 郵局 |

:::tip
還沒開戶的話，中國信託、國泰世華、郵局都是校內取款方便的選擇。郵局那台在行政區，順便可以辦存簿與匯款。
:::

## 電子設備

### 平板要不要買

:::info
統一回答：**平板不是必備，但真的很方便**，而且可以省下買書的錢。大部分同學都有，少數沒有的人也過得好好的。

如果你本來就不太買教科書，那買不買的差異就更小了。
:::

### 筆電與平板怎麼選

如果預算只能選一個，用這個順序判斷：

:::steps
1. **看預算**：都買得起當然都買，這題就結束了
2. **會不會搬桌機去宿舍**：不搬的話，==筆電幾乎是必需品==。電資、資工類科系多少要寫程式，平板目前大多做不到
3. **會不會常在外面工作**：會搬桌機、但常在圖書館或咖啡廳做事，仍然建議筆電
4. **以上都不是**：那平板就很夠用了
:::

上面是以電資類科系為例，其他科系原則大同小異，差別在你的作業型態需不需要完整的桌面環境。

### 品牌

平板市場實際上只分成 iPad 和其他。學生方案（教育商店）的價格與贈品都相當有感，決定要買之前先去[教育商店](https://www.apple.com/tw-edu/store)比一比。

:::warning
教科書電子檔不是每一本都找得到，找得到的來源也不一定合法。決定用平板取代實體書之前，先確認你這學期的課本狀況。

另外提醒自己一句話：**不要買前生產力、買後 Netflix**。
:::

## 貓

校園裡有幾隻常駐的浪貓，各有名字與地盤——牛奶、皮皮、小咪、虎斑，還有幾隻要看運氣才遇得到的隱藏版。趕作業趕到懷疑人生的時候，去找牠們待五分鐘很有用。

:::warning
請不要餵食人類食物，也不要追著牠們跑。牠們過得好好的，維持距離就是最好的照顧。
:::
